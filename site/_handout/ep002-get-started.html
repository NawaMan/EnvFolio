EnvFolio

Let's get you started with `EnvFolio`.

Follow these five quick steps:

install the program

initialize the store

add texts and secrets

view them

and use them.

EnvFolio

Next, run `folio init`. It makes your store, and a GPG key to protect it.

Use a key you have, or make a new one.

In the newly-setup case, folio will create a new key.

So, you will be asked for your name, your email, and the type of key.

Then, you will be asked for a passphrase needed to use the key.

The passphrase cannot be reset, so never lose it.

step 3

folio insert

📄 text
plain, signed
given on the command line
🔑 secret
encrypted
asked twice, never shown

Insert plain text item.

EnvFolio
$folio insert text -t demo@example.com gh/user
$

Insert secret item.

EnvFolio
$folio insert secret gh/token
Enter password for gh/token:
Retype password for gh/token:
[master f696965] Add given password for gh/token to store.
$

EnvFolio

A text goes in plain, on the command line or at a prompt, and folio signs it.

A secret is asked at a hidden prompt, twice.

step 4

Every name, then one value.

$
names: folio ls · ls text · ls secret
one value: folio show text|secret
EnvFolio

Folio `ls` shows items all as a tree: names only, no values.

A key marks a secret, and a page marks a text.

Folio show prints one. You say text or secret, so a secret is never shown by accident.

Add -c, and it copies the secret to the clipboard instead and clears it after 45 seconds.

folio exec

📄 texts come by default
🔑 secrets only with -s
the first secret read
pinentry asks for your passphrase,
then gpg-agent remembers it a while.
EnvFolio

To use them, run your command through `folio exec`.

The folder `gh` holds a secret token, and a plain-text user.

So, `folio exec` gives the command the variable GH_TOKEN and GH_USER.

Texts come by default. But secrets come only with dash s.

step 5 · use them

folio shell

The same, for a whole session.

EnvFolio
$folio shell -s gh
folio shell: loaded GH_TOKEN, GH_USER (texts: 1, secrets: 1). Type 'exit' to leave.
$echo $GH_USER
demo@example.com
$gh repo list
…
$exit
$
names printed, never values
exit to leave
EnvFolio

For a whole session, folio shell starts your shell with them.

It prints the names it loaded, never the values.

Inside, every command can use them. gh, for one, picks up the token by itself.

Type exit to leave.
