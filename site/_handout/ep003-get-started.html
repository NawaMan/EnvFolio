Folio

After installing, you will need to create the folio store to keep the items.

Run `folio init` and follow the instruction to either

create a key or use an existing one to protect the store

In the newly-setup case like this example here, `folio` will create a new key.

So, you will be asked for your name, your email, and the type of key.

Then, you will be asked for a passphrase needed to use the key.

The passphrase cannot be reset or recover,

so make sure to remember it AND never lose it.

Folio

`folio insert` can be used to add/replace an item.

`folio insert text`, for instance, will add text item.

Inserting text will take from the command line or at a prompt

Then it value will be signed, so it will ask or the passphrase.

Similar command to add a secret item.

Then, the value will be prompt with a hidden prompt, twice.

Folio

The items can be used by injected directly into a command using `folio exec`.

In this example, the folder `gh` holds a GitHub secret token, and a GitHub plain-text user name.

`folio exec` passed on the item values as GH_TOKEN and GH_USER environmental variables.

Text values are passed on by default.

But secret values requires `--secrets` or `-s` -- just to be sure that it was intentional.

step 4 · use them · shell

folio shell

The same, for a whole session.

Folio
$folio shell -s gh
folio shell: loaded GH_TOKEN, GH_USER (texts: 1, secrets: 1). Type 'exit' to leave.
$echo $GH_USER
demo@example.com
$gh repo list
…
$exit
$
names printed, never values
exit to leave
Folio

For a whole shell session, `folio shell` starts your one with the selected items.

It prints the loaded item names -- only the names never the values.

Inside the shell session, those appear exported environmental variables.

So every commands can use them.

`gh` -- the GitHub CLI command, for example, picks up the token by itself.

Once you are done, type exit to leave.

Copied gh/token to clipboard. Will clear in 45 seconds.
$
names: folio ls · ls text · ls secret
one value: folio show text|secret
Folio

Folio `ls` or `list` displays items as a tree: just the item names only, no values.

A key marks a secret, and a page marks a text.

Folio show prints one item.

You need to specify if you want text or secret, so a secret is never shown by accident.

Add -c, and it copies the secret to the clipboard instead and clears it after 45 seconds.
